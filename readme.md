# CampusPulse

**CampusPulse** is a Smart Campus Service Management Platform. 

## What is CampusPulse?
It is a web application that allows students on a college campus to report problems or request services. For example, a student can report that the Wi-Fi is down in a hostel or that a projector is broken in a classroom.

## Technology Stack
For this beginner version (V0.1), we are using:
- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Backend:** Python, FastAPI
- **Database:** SQLite

## Goal
The goal of this V0.1 project is to understand the absolute fundamentals of Computer Science, Client-Server Architecture, and Web Development.
